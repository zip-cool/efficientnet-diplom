# Контекст дипломной работы для Codex

Тема дипломной работы: оптимизация использования сверточной нейронной сети EfficientNet для классификации изображений листьев картофеля.

В проекте не разрабатывается новая архитектура нейронной сети. Основная идея работы заключается в исследовании того, как наиболее эффективно использовать уже существующую предварительно обученную модель EfficientNet для прикладной задачи классификации изображений.

## Задача проекта

Решается задача многоклассовой классификации изображений листьев картофеля.

Классы:

- здоровый лист картофеля;
- альтернариоз;
- фитофтороз.

На вход модели подается изображение листа картофеля. На выходе модель должна определить один из трех классов.

## Набор данных

Используется Irish Potato Dataset.

Особенность набора данных состоит в том, что изображения получены в реальных полевых условиях. Поэтому фотографии могут отличаться:

- освещением;
- фоном;
- углом съемки;
- масштабом листа;
- расстоянием до объекта;
- количеством листьев в кадре.

В рамках данной работы модель классифицирует изображение целиком. Задача детектирования или сегментации каждого отдельного листа не решается.

## Модель

В качестве базовой модели используется EfficientNet, желательно EfficientNetB0 как основной вариант для экспериментов.

Используется подход transfer learning:

- берется EfficientNet с предварительно обученными весами;
- исходная классификационная часть модели заменяется новой;
- новая классификационная часть адаптируется под 3 класса;
- далее сравниваются разные режимы обучения модели.

## Метрики качества

Для оценки качества модели используются:

- accuracy;
- precision;
- recall;
- F1-score;
- loss;
- confusion matrix;
- время обучения.

Время обучения нужно сохранять обязательно, потому что тема диплома связана не только с максимальной точностью, но и с оптимизацией использования EfficientNet.

## Общая логика экспериментов

Эксперименты должны проводиться последовательно.

Сначала фиксируется один объем обучающей выборки, например 1000 изображений или полный подготовленный набор данных. На этом одинаковом объеме данных сравниваются разные режимы обучения EfficientNet.

После выбора лучшего режима обучения этот режим фиксируется. Затем уже исследуется влияние объема обучающей выборки: 200, 500, 1000 изображений и полный набор данных.

Важно не менять одновременно и метод обучения, и объем данных. Иначе будет непонятно, какой фактор повлиял на результат.

## Эксперимент 1. Обучение только классификационной головы

В этом эксперименте основная часть EfficientNet замораживается.

Обучается только новая классификационная часть модели.

Цель эксперимента:

- получить базовое качество модели;
- проверить, достаточно ли признаков, извлеченных предобученной EfficientNet;
- оценить скорость обучения;
- проверить наличие переобучения.

Нужно сохранить:

- train accuracy;
- validation accuracy;
- train loss;
- validation loss;
- test accuracy;
- precision;
- recall;
- F1-score;
- confusion matrix;
- время обучения;
- путь к сохраненной модели.

## Эксперимент 2. Fine-tuning последних слоев

После обучения классификационной головы размораживается часть последних слоев EfficientNet.

Дообучение выполняется с малым learning rate.

Цель эксперимента:

- проверить, улучшает ли fine-tuning качество классификации;
- сравнить результат с обучением только классификационной головы;
- определить, есть ли смысл дообучать последние слои модели на целевом датасете.

Условия эксперимента должны быть такими же, как в первом эксперименте: тот же объем данных, то же разбиение на train, validation и test.

## Эксперимент 3. Влияние аугментации данных

В этом эксперименте сравниваются два варианта:

- обучение без аугментации;
- обучение с аугментацией.

Возможные виды аугментации:

- случайный поворот;
- горизонтальное отражение;
- изменение яркости;
- изменение контрастности;
- масштабирование;
- небольшие сдвиги изображения.

Цель эксперимента:

- проверить, помогает ли аугментация повысить качество модели;
- уменьшить переобучение;
- повысить устойчивость модели к разным условиям съемки.

Это особенно важно, потому что изображения в датасете сделаны в полевых условиях.

## Эксперимент 4. Влияние объема обучающей выборки

Для этого эксперимента используется лучший режим обучения, выбранный по результатам предыдущих экспериментов.

Модель обучается на разных объемах данных:

- 200 изображений;
- 500 изображений;
- 1000 изображений;
- полный набор данных.

Цель эксперимента:

- исследовать, как количество обучающих изображений влияет на качество EfficientNet;
- определить рациональный объем обучающей выборки;
- оценить соотношение между качеством классификации и временем обучения.

Оптимальным считается не обязательно самый большой объем данных. Более важен баланс:

- достаточно высокий F1-score;
- приемлемая accuracy;
- умеренное время обучения;
- отсутствие сильного переобучения.

Если полный набор данных дает только небольшой прирост качества по сравнению с 1000 изображениями, но требует заметно больше времени обучения, то объем 1000 изображений можно считать более рациональным вариантом.

## Правила для реализации экспериментов

Codex должен учитывать следующие правила:

- не смешивать несколько факторов в одном эксперименте;
- сначала сравнивать методы обучения при одинаковом объеме данных;
- затем сравнивать объемы данных при выбранном лучшем методе обучения;
- использовать фиксированный random seed;
- использовать стратифицированное разбиение на train, validation и test;
- сохранять результаты экспериментов в csv или json;
- сохранять графики accuracy и loss;
- сохранять confusion matrix для тестовой выборки;
- сохранять обученные модели или checkpoints;
- отдельно фиксировать время обучения;
- не ожидать слишком высокой точности, так как полевые изображения сложнее лабораторных.
